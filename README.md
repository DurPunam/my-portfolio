# Durgesh Kumar - Portfolio Website

A modern, responsive portfolio website showcasing my journey as a tech enthusiast and B.Tech student at VIT Chennai.

## Features

- **Responsive Design**: Optimized for all devices (desktop, tablet, mobile)
- **Modern UI**: Clean, professional design with smooth animations
- **Interactive Elements**: 
  - Typing text animation
  - Animated profile rings
  - Smooth scrolling navigation
  - Hover effects and transitions

## Technologies Used

- HTML5
- CSS3 (with advanced animations and gradients)
- JavaScript (ES6+)
- Font Awesome icons

## About Me

I'm a 2nd-year B.Tech student at VIT Chennai, serving as Secretary of the Code-Y-Gen Club. I'm also an active participant in the Google Arcade program, constantly exploring new challenges in coding and design.

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No build process required.
